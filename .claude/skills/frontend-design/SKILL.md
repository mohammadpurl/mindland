# Mindland Frontend Design System

Use a futuristic but friendly educational aesthetic.

Design Principles:
- Clean whitespace
- Soft gradients
- Rounded corners (16px-24px)
- Smooth motion
- Accessible contrast
- Minimal but immersive UI

Typography:
- Use clear hierarchy
- Large bold hero titles
- Calm readable paragraph widths

Colors:
- Primary: Purple/Blue gradient
- Accent: Neon green
- Neutral backgrounds

Animations:
- Smooth reveal on scroll
- Floating elements
- Subtle hover scaling
- Soft transitions

Avoid:
- Generic Tailwind layouts
- Harsh shadows
- Overcrowded UI
- Excessive animations

Mobile:
- Mobile-first
- Responsive typography
- Adaptive spacing
