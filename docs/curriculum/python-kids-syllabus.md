## ۱. اصول طراحی دوره

| اصل | توضیح |
|-----|--------|
| از ملموس به انتزاعی | اول چاپ و بازی → بعد شرط/حلقه → بعد داده → بعد تابع → بعد پروژه گرافیکی |
| یک ستون، دو عمق | همان شماره درس برای هر دو رده؛ تفاوت در «سطح A / سطح B» |
| بدون تکرار ریاضی | عملیات عددی فقط ابزار است؛ در صورت نیاز ارجاع به مدرسه‌ی ریاضیات |
| بلوکی اختیاری ولی توصیه‌شده | قبل از پایتون، ایستگاه Scratch/بلوکی منطق را نرم می‌کند |
| محیط پیشنهادی | Trinket یا Replit (وب)؛ IDLE فرعی |
| گرافیک MVP | turtle اولویت؛ pygame فقط مسیر B پیشرفته / اختیاری |
| قالب هر جلسه | هدف → استعاره → دمو زنده → تمرین → چالش آزاد (A/B) → جمع‌بندی بازیگوش |
| مدت جلسه | ۴۵–۵۰ دقیقه (+ تا ۱۰ دقیقه بافر پروژه) |

### تفاوت رده‌ها در یک نگاه

| | رده A (۹–۱۱) | رده B (۱۲–۱۴) |
|--|--------------|----------------|
| استعاره | داستان، جعبه، ربات کوچک | کمی فنی‌تر، «مهندس کوچک» |
| کد | کوتاه، یک مفهوم در هر بار | همان مفهوم + یک لایه اضافه |
| خطا | معلم با هم دیباگ می‌کند | دانش‌آموز خطای خودش را می‌خواند |
| پروژه | قالب آماده‌تر | آزادی طراحی بیشتر |
| واژه‌ها | فارسیِ خودمانی + چند واژه‌ی انگلیسی ضروری | واژه‌های انگلیسی رایج‌تر در کد |
